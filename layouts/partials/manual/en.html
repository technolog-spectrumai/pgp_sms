What this tool does

PGP SMS turns a short text message into scrambled text that only one chosen person can read. You can then send that scrambled text by SMS, email or chat. Anyone who intercepts it sees meaningless characters.

Nothing leaves your browser. There is no server behind this page. Your messages, keys and passwords are never sent anywhere, and closing the tab erases them.

Key words, in plain language

Think of a padlock and its key.

Public key: the open padlock
You can hand out copies freely. Anyone holding it can lock a message for you, but nobody can unlock it with it. Safe to email or publish.
Private key: the only key to that padlock
It unlocks messages that were locked with your public key. Keep it secret, like a house key. Whoever has it can read your messages.
Key pair
A matching public key and private key, created together. Each person needs their own pair.
Passphrase
A password that protects your private key. Even if someone copies the key file, they cannot use it without the passphrase.
Encrypted message, or PGP1: text
The scrambled result. It starts with PGP1: followed by a long run of letters and digits. It must be copied whole: a single missing character breaks it.

First-time setup

  1. Open the Create key pair tab and create your own key pair.
  2. Save your private key with Download .asc and store the file somewhere safe and private.
  3. Send your public key to the people who will write to you.
  4. Ask each of them for their public key, so you can write back.

Send a secret message: Encrypt

  1. Open the Encrypt tab.
  2. In Recipient public key, paste the public key of the person you are writing to, or use Load key file.
  3. Type your text in Message.
  4. Press Encrypt, then Copy encrypted text.
  5. Paste it into your SMS, email or chat and send it.

Use the recipient's public key, not your own. A message locked with your own key can only be opened by you.

Read a secret message: Decrypt

  1. Open the Decrypt tab.
  2. In Private key, paste your own private key, or use Load key file.
  3. Paste the whole received text, starting with PGP1:, into Encrypted message.
  4. If your key has a passphrase, type it into Private-key passphrase.
  5. Press Decrypt. The readable text appears under Plaintext.

Create a key pair

  1. Open the Create key pair tab.
  2. Enter a Name and an Email. They are labels that help others recognise your key. Nothing is sent to that address.
  3. Choose a Private-key passphrase. It is optional, but strongly recommended.
  4. Press Generate key pair.
  5. Use Download .asc for both keys, or Copy to copy them.

There is no recovery. If you lose your private key or forget its passphrase, messages sent to you can never be read again. Nobody, including us, can restore them.

When something goes wrong

Message on screenWhat it means and what to do
Decryption key is not decryptedYour private key has a passphrase, but none was entered. Type it into Private-key passphrase and press Decrypt again.
Incorrect key passphraseThe passphrase is wrong. Check for typos and Caps Lock.
No decryption key packets foundThe message was locked for a different key. The sender probably used someone else's public key, or you pasted the wrong private key.
Error during parsingThe encrypted text is incomplete or altered. Ask for it again and make sure all of it, from PGP1: to the last character, is copied.
Misformed armored textThe key is not a valid key. Paste the whole block, including the -----BEGIN and -----END lines.

Encrypted text is several times longer than the original. A long message may be split into several SMS by your phone. The receiver must join all parts, in order, before decrypting.

Safety rules

  • Never send your private key to anyone. Only the public key is meant to be shared.
  • Protect the private key with a passphrase and do not write the passphrase next to the key file.
  • Keep a backup of the private key file, for example on an encrypted USB drive.
  • Check a new public key with its owner, for example by phone, before sending anything sensitive.

Quick test in two minutes

Useful for testers, or to check everything works before relying on it.

  1. Create key pair: generate a pair with the passphrase test.
  2. Encrypt: paste the new public key, type hello, press Encrypt, copy the result.
  3. Decrypt: paste the new private key, paste the copied text, enter test, press Decrypt.
  4. Expected result: hello appears under Plaintext.
